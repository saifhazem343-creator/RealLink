RealLink — نفس التصميم مع تجهيز قاعدة بيانات ومزامنة أونلاين

مهم: هذه نسخة جاهزة للربط والنشر، لكنها لن تتصل بالإنترنت حتى تضع مفاتيح مشروع Supabase الخاص بك في config.js وتشغّل SQL.
لا توجد اشتراكات أو خدمات مدفوعة مطلوبة لهذه الخطوات، ضمن حدود الخطط المجانية المتاحة وقت الإعداد.

1) إنشاء قاعدة بيانات مجانية
- أنشئ مشروعًا في https://supabase.com/ وسجّل الدخول.
- من Project Settings > API انسخ Project URL و anon/public key.
- ضع القيم في config.js بدل YOUR_SUPABASE_PROJECT_URL و YOUR_SUPABASE_ANON_KEY.
- لا تضع service_role key في الموقع أبدًا.

2) تجهيز الجداول والصور
- افتح SQL Editor في مشروع Supabase.
- افتح ملف supabase.sql وانسخ محتواه كاملًا إلى SQL Editor ثم اضغط Run.
- من Authentication > Providers تأكد من تفعيل Email.
- يمكن أن يحتاج المستخدم لتأكيد بريده قبل تسجيل الدخول حسب إعدادات المشروع.

3) الاستضافة المجانية
- ارفع index.html و config.js إلى استضافة صفحات ثابتة مثل Netlify أو Cloudflare Pages.
- يجب رفع الملفين معًا في نفس المجلد؛ لا تفتح index.html محليًا مباشرة بعد الربط، استخدم رابط الاستضافة HTTPS.
- لا أستطيع النشر نيابة عنك دون صلاحية لحساب الاستضافة. لا ترسل كلمة مرور حسابك هنا.

4) ما الذي يعمل بعد الإعداد؟
- تصفح الوحدات التجريبية، والبحث والفلاتر والمفضلة بنفس التصميم.
- إنشاء حساب/تسجيل دخول بالبريد وكلمة المرور.
- المطور المسجل يستطيع نشر وحدة وصورها الاختيارية (حتى 8 صور، 5MB لكل صورة).
- الوحدات المنشورة تُقرأ من قاعدة البيانات أونلاين وتظهر عبر الأجهزة.
- سياسة قاعدة البيانات تسمح للزوار بقراءة الوحدات، وكل مطور يضيف وحداته باسم حسابه.

ملاحظات مهمة
- الوحدات التجريبية الست المعروضة في الواجهة أمثلة وليست بيانات عقارية حقيقية.
- نموذج الاستفسارات والمفضلة لا يزالان محليين في هذه النسخة؛ لم يتم ربط الاستفسارات بقاعدة البيانات بعد.
- لا توجد حتى الآن تطبيقات أصلية منشورة على متاجر iPhone/Android؛ هذه واجهة ويب متجاوبة ويمكن لاحقًا تحويلها إلى PWA/تطبيق.
- لا تشارك مفاتيح سرية أو كلمة مرور Supabase. مفتاح anon/public مخصص للواجهة ويعتمد أمانه على سياسات RLS الموجودة في supabase.sql.
